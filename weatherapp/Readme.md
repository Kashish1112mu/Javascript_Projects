# Weather Dashboard 🌦️

A simple, responsive weather dashboard built using HTML, CSS, and JavaScript. It fetches real-time weather information for a city using the Open-Meteo API.

## Features

- Search for a city by name
- Fetch geographic coordinates using the Open-Meteo Geocoding API
- Display current temperature
- Show relative humidity and feels-like temperature
- Display a basic weather description
- Handle invalid city searches and API request errors

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API

## APIs Used

- **Geocoding API:** Finds a city's geographic coordinates.
- **Weather Forecast API:** Retrieves current weather information for the selected location.

Both APIs are provided by [Open-Meteo](https://open-meteo.com/).

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name and click **Search**.

No API key is required for this project.
